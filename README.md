## papers/
- 01_HippoRAG2_ICML2025.pdf: HippoRAG 2, "From RAG to Memory" (Ohio State University, ICML 2025). Es el núcleo del motor. Código: https://github.com/OSU-NLP-Group/HippoRAG
- 02_HippoRAG_v1_NeurIPS2024.pdf: HippoRAG, la versión original (NeurIPS 2024).

## documentos/ (plantillas, solo con secciones)
- 01_Documento_de_Producto.docx: qué es el producto y por qué existe: el problema, los objetivos, los usuarios, el alcance, lo que queda fuera y cómo se mide el éxito.
- 02_Especificacion_de_Requerimientos.docx: qué debe hacer el motor y con qué calidad: requerimientos funcionales y no funcionales, datos, interfaces y criterios de aceptación.
- 03_Documento_de_Arquitectura.docx: cómo se construye: componentes, flujo de datos, interfaces y decisiones técnicas.
- 04_Plan_de_Evaluacion.docx: cómo se comprueba que funciona: conjunto de preguntas, métricas, baselines y criterios de aceptación.
- 05_Plan_de_Proyecto.docx: cómo se organiza el trabajo: fases, entregables, cronograma y criterios para pasar de una fase a otra.
- 06_Registro_de_Riesgos.docx: tabla para anotar los riesgos, su impacto y cómo se mitigan.
- 07_Registro_de_Decisiones.docx: tabla para anotar cada decisión importante, por qué se tomó y qué alternativas se descartaron.
